# Simple Calculator

This is a simple calculator project I built to practice the basics of web development with HTML, CSS, and JavaScript.

## Live demo

Once GitHub Pages is enabled, open the calculator here:

[https://ud4uddav.github.io/simpleCalculator/](https://ud4uddav.github.io/simpleCalculator/)

## Features

- Addition, subtraction, multiplication, and division
- Decimal numbers and percentages
- Clear and delete buttons
- A clean, responsive layout that also works on smaller screens

## Run it locally

1. Open `index.html` in a web browser, or open this folder in VS Code and use a local-preview extension.
2. Click the calculator buttons to enter an expression.
3. Press `=` to see the result.

No installation or special setup is required.

## Project structure

- `index.html` creates the calculator display and buttons.
- `style.css` controls the layout, colors, and button styles.
- `script.js` handles button presses and calculations.

## Publish updates to GitHub

Create a new empty repository on GitHub, then run these commands in this project folder (replace the URL with your repository URL):

```bash
git init
git add index.html style.css script.js README.md
git commit -m "Create simple calculator"
git branch -M main
git remote add origin https://github.com/YOUR-USERNAME/YOUR-REPOSITORY.git
git push -u origin main
```

GitHub may open a browser window and ask you to sign in when you push.
